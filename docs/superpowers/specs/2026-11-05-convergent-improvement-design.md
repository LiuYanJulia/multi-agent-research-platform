# Convergent Guidance as Integrated Improvement

## Intent

Convergent (C) guidance should help a participant improve how several of their existing ideas work together. It should make the lineage from those earlier ideas visible and retain practical usefulness; it must not treat convergence as an excuse to invent a disconnected, overly ambitious proposal.

## Chosen Approach

Use **integrated improvement** as the common definition for both C conditions.

- **C-high:** one substantial integrated improvement across the selected earlier ideas. “Substantial” describes the scope of the integration, not novelty for its own sake: retain the earlier ideas' useful roles and improve their coordination, decision logic, responsibility allocation, or end-to-end service flow. The new element must resolve a concrete gap, friction, dependency, or trade-off in their joint operation.
- **C-low:** one focused improvement at the connection between earlier ideas. Add or refine a small feature, trigger, handoff, access step, role, or feedback loop that makes two existing elements work together better. Keep the existing approach and scope intact.

## Participant-Facing Guidance

Within the existing limits (C-high: 80 words; C-low: 50 words), the first sentence must make the improvement traceable: name the relevant earlier ideas or roles, identify the improved connection, and state the added or revised mechanism. Concise points then explain the existing friction or gap, how the improvement operates, and its practical benefit.

Illustrative shape: “To improve how [idea A] and [idea B] work together, add [mechanism].”

## Non-goals

- Do not require high-C to be radical, citywide, or less useful in order to be “high”.
- Do not replace the participant's earlier ideas with a parallel programme.
- Do not change divergent conditions, word limits, planner-call structure, memory inputs, or anti-repetition logic.

## Acceptance Criteria

- C-high prompt describes a substantial integrated improvement that retains usefulness and existing roles.
- C-low prompt describes a focused feature-level connection improvement.
- Final C guidance explicitly communicates the source ideas, the improvement, operation, and practical benefit within existing word limits.
- Automated prompt-contract tests protect these distinctions.
